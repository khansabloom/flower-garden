# 🌸 Flower Garden
Game web ringan, responsif, dan siap di-deploy ke GitHub Pages.

## Cara menjalankan
Buka `index.html` di browser. Semua data game tersimpan di localStorage.

## Deploy ke GitHub Pages
1. Buat repository GitHub baru.
2. Upload `index.html`, `style.css`, `script.js`, dan `data.json`.
3. Masuk **Settings → Pages**.
4. Pada Source pilih **Deploy from a branch**, pilih branch `main` dan folder `/ (root)`.
5. Simpan dan tunggu GitHub Pages membuat alamat website.

Tidak memakai framework atau library eksternal, jadi ringan dan mudah dikembangkan.


## Revisi favicon
Website sekarang sudah memakai favicon Flower Garden:
- `favicon.svg` — versi vector utama.
- `favicon-512.png` — versi PNG resolusi tinggi.
- `favicon.png` — versi PNG 128×128.
Favicon dipasang langsung di `index.html`, jadi otomatis tampil di tab browser.
